Pulse: async job processing

A background job platform: clients submit jobs over a REST API, and Celery workers run them with retries, idempotency and a dead-letter queue. Every state change is recorded in PostgreSQL and shown on a live dashboard.

  • Exponential backoff with jitter, transient vs permanent errors
  • Idempotency keys stop duplicate jobs under concurrency
  • Load-tested with 5,000 jobs: 0 lost, 0 duplicated
  • Kubernetes manifests with autoscaling, Terraform for AWS
